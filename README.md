# RUKA – Rural–Urban Market Connection Platform

RUKA is a local e-commerce startup platform designed to **bridge the gap between rural farmers and urban consumers**.  
It enables farmers to sell produce directly, provides consumers access to fresh and diverse food, and supports local entrepreneurs and developers in building digital market solutions.

## Key Features
- Farmer dashboards to manage products and stock
- Consumer interfaces for browsing, ordering, and subscription boxes
- Dummy payment options for prototype demonstration (Telebirr, Mobile Money, Card)
- Marketplace aggregation for rural-urban distribution
- SMS/USSD-ready design for low connectivity environments
- Admin dashboard for monitoring users, products, and transactions
- Developer-friendly APIs for extensions and integrations

## Tech Stack
- Backend: Python, FastAPI, SQLAlchemy
- Frontend: React, Tailwind CSS
- Database: PostgreSQL
- Optional: Africa’s Talking sandbox integration for SMS and mobile money

## Purpose
RUKA demonstrates **affordable, scalable solutions for rural-urban market access**, highlighting:
- Human-centered design
- Low-cost, practical logistics
- Small business and cooperative empowerment
- Digital literacy and inclusion

## Status
- Fully modular prototype
